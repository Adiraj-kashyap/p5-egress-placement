## Per-component own-cost minimisers (core set)

Own cost of component c at l = compute + storage + internet GB x internet rate (no inter-component egress). If one location minimises the own cost of every component, placing everything there is optimal for every traffic scale s >= 0, because inter-component egress is >= 0 and is 0 when all components share a location.
